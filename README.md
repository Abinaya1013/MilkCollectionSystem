# 🥛 Village Milk Collection & Payment Register

## 📌 Project Overview

This is a web-based Milk Collection Management System developed using HTML, CSS, and JavaScript. The application helps manage daily milk collection records by allowing users to add, edit, delete, search, and filter records. It also calculates the amount and running total automatically.

---

## 🎯 Features

- Add Milk Collection Record
- Edit Existing Record
- Delete Record
- Search Member
- Filter by Shift
- Filter by Fat Percentage
- Automatic Amount Calculation
- Running Total Calculation
- Input Validation
- User-Friendly Interface

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript

## 🧮 Calculations

- Amount = Quantity × Rate
- Running Total = Previous Total + Current Amount

## ▶️ How to Run

1. Open the project folder.
2. Open `milk.html` in any modern web browser.
3. Start using the application.
